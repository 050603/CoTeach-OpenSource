# 幻灯片渲染器设计合同

`@openmaic/renderer` 从 `@openmaic/dsl` 读取页面类型，负责只读显示、当前播放视觉效果和浏览器快照。公开接口与验证命令见 [README.md](README.md)。

## 职责与依赖

- `SlideCanvas` 处理父容器测量、画布比例、缩放、背景与展示壳。
- `SlideElement` 和 `elements/` 处理九种基础元素，不读取应用业务状态。
- `context.tsx` 提供可选 Provider；props 优先，缺少页面数据时明确报错。
- `effects/` 与视觉目标解析根据当前 DOM 和 DSL 几何显示激光、聚光、高亮与缩放。
- `styles.ts` 提供段落、表格和效果样式；`snapshot/` 使用同一画布生成浏览器 PNG。
- `renderImage`、`renderVideo` 和 `onElementClick` 将媒体、权限或交互行为留给调用方。

渲染器不生成讲稿、不请求模型、不管理教师/学生角色、不执行课堂阶段转换，也不提供完整课件编辑工作台。现有编辑器位于应用组件，不能把历史“下一版本编辑能力”草案当作已实现包 API。

## 几何合同

页面使用 `viewportSize` 与 `viewportRatio`，元素使用 DSL 坐标。布局计量、教学播放器和截图应使用相同字体、段落、表格和公式规则。应用的页面主题与展示壳不能写回源页面背景。

细粒度视觉目标保留元素 ID 与 selector，文本引用需按实际字形位置处理换行片段。激光的目标切换由播放引擎按讲稿时间驱动，渲染器只呈现当前目标与短过渡。回放、定位失败与缺失目标必须保留可解释的状态，不凭空构造目标。

## 截图与字体

屏幕预览默认保留展示壳，PNG 比较与导出关闭 `chrome`。快照等待字体与媒体就绪；字体替换、资源失败或跨域污染可能影响结果，不能把成功生成图片等同于源 PPT 还原质量通过。

外部 `fonts.css` 与 CoTeach 的同源课程字体是不同配置。修改字体或文本计量时核对 [FONTS.md](FONTS.md)、具体字体配置与应用计量调用，许可和来源随分发保留。

## 维护

DSL、导入器和渲染器共享契约。协议扩展先核对 DSL，再更新生产者、实际渲染和最小回归；只读 UI 修改按受影响元素及实际画面验证。应用特有的来源、教学质量与恢复规则维护在 [课程生成合同](../../../docs/course-generation.md)，不复制为另一套包内教学逻辑。
