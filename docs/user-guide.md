# CoTeach 使用说明

CoTeach 将备课资料、可复用课程、教学班活动和学生课堂学习连接起来。教师先在课程库完成备课并发布，再把课程安排到教学班；学生用教学班邀请码加入课程，从课程目录进入活动和课堂。

本文面向教师和学生。安装与配置见 [项目说明](../README.md)，维护文档见 [文档导航](README.md)。文中的页面路径附在实际部署地址之后，例如 `/teacher/login`。

## 第一次使用

| 使用者 | 最短操作路径 | 完成标志 |
| --- | --- | --- |
| 教师备课 | 登录 → 个人中心配置所需 AI 服务 → 课程库新建课程 → 导入交接包或 AI 协同备课 → 生成与审阅 → 发布 | 课程库显示已发布版本，可用于课堂活动 |
| 教师开课 | 教学班 → 新建教学班 → 添加章节和课堂活动 → 关联已发布课程 → 开放教学班、章节和活动 → 分发邀请码 → 开始上课 | 学生能从目录进入本场课堂 |
| 学生学习 | 使用邀请码注册或加入课程 → 打开课堂活动 → 按要求完成前测 → 进入课堂 → 学习、提交成果和项目评价；课后按教师安排完成实验后测 | 页面显示正式提交记录，教师能查看本场记录 |

如果课程只安排作业、问卷、独立后测或资料，可直接在教学班目录添加相应活动，无需先生成课堂课程。AI 服务配置由教师管理，学生使用所属课堂的服务。

按任务阅读：[备课](#教师备课) · [组织教学班](#教师组织教学班) · [课堂学习](#五阶段课堂) · [项目成果](#学生完成项目成果) · [问卷与后测](#问卷与测评选择) · [结课回看与导出](#查看记录与导出)。

## 入口与基本概念

| 使用者 | 入口 | 用途 |
| --- | --- | --- |
| 教师 | `/teacher/login` | 登录教师账号 |
| 教师 | `/teacher/classes` | 创建教学班、编排章节和活动、管理学生 |
| 教师 | `/teacher/templates` | 新建、生成、审阅和发布可复用课程 |
| 教师 | `/teacher/textbooks` | 导入教材、阅读章节和查看知识图谱 |
| 教师 | 右上角账号菜单 → 个人中心 | 管理账号、教学偏好和 AI 服务 |
| 学生 | `/student/login` | 登录学生账号 |
| 学生 | `/student` | 查看已加入课程、使用邀请码加入新课程 |
| 学生 | 右上角账号菜单 → 个人中心 | 查看姓名和登录账号，了解密码重置流程 |

几个名称对应不同的教学用途：

- **课程库课程**是可复用的教案和课堂资源。发布后产生一个固定版本。
- **教学班**是面向一批学生的学习空间，包含课程介绍、章节、活动和学生名单。
- **活动**是章节中的课堂、作业、测验、问卷、后测或资料。
- **课堂场次**是某次实际授课。它使用活动关联的已发布课程版本，单独保存学生参与和学习记录。

修改课程草稿后需要重新发布，已安排的课堂继续使用原来关联的版本。再次授课会建立新场次，上一场的学习记录保留。

## 账号与加入课程

教师使用教师登录入口。系统没有教师账号时，可从教师注册页创建首个账号；已有教师账号后，登录教师可从账号菜单中的“创建教师账号”增加教师账号。

学生首次使用时，在 `/student/register` 输入教师提供的 6 位课程邀请码，确认课程和任课教师，再填写登录账号、姓名和密码。注册成功后加入该课程。已有账号的学生直接登录，在“我的课程”中选择“加入课程”，输入另一门课程的邀请码，无需重复注册。

只有一门课程时，学生登录后可能直接进入课程主页；点击“我的课程”可回到完整列表。

忘记密码时，学生在登录页点击“忘记密码”，填写学号和姓名提交申请，并保留当前浏览器页面。教师进入教学班的学生管理，选中该学生，在账号管理中核对本人和当前申请后点击“允许重置密码”。学生页面会自动显示新密码输入框，设置并确认后即可重新登录，无需传递重置链接或保存恢复码。

申请等待时间为 30 分钟，教师允许后需在 10 分钟内完成。授权仅适用于提交申请的浏览器，完成一次改密即失效，原登录状态同时失效。教师可以取消申请；申请过期或被取消后，学生可重新申请。如果换了浏览器而无法返回原申请，请教师先取消该申请，再在当前浏览器重新提交。

## 教师备课

### 1. 建立教材库

在“教材库”选择“导入教材”，上传 **DOCX 文件，单文件不超过 80 MiB**。系统提取章节、知识、案例与插图，并建立检索索引。列表显示等待解析、正在解析、可用于课程、解析失败等状态，处理中会自动更新；进度百分比是阶段估计。

打开教材后，可以：

- 通过目录阅读章节原文，查看相关知识点及其来源。
- 切换到“知识图谱”，从整书或章节查看知识之间的联系。
- 搜索章节、原文和知识内容，并跳转到对应位置。
- 解析失败时使用“重新解析”；提示等待检索服务时，请在教师个人中心检查“教材语义检索”服务配置。

教材归档后不再供新课程选择，已有课程引用、教材原文与解析结果继续保留；恢复后可再次用于新课程。

### 2. 新建课程并确认教学资料

在“课程库”点击“新建课程”，进入备课页。可以选择“导入交接包”沿用已有资料，也可以选择“AI 协同备课”，直接描述希望开展的课程。

**AI 协同备课**：先说明课程想法，AI 会根据已有信息逐题讨论教学对象、时长、知识深度、教法和评价。每题可选具体方案，也可输入自己的想法、反问或修改前面的结论。右侧方案区区分已明确要求和 AI 建议，窄屏可展开查看。教材与资料均可选；已提交的对话保存在服务器，离开后可回来继续。

当 AI 建议收束时，可以继续深入，也可以审阅完整方案。确认课程目标、知识范围和五阶段时间安排后，点击“确认方案并开始生成”，进入与交接包模式相同的生成流程。修改方案需要重新确认。无启动 PPT 时，课堂会展示任务与目标说明卡；也可通过已有入口补充启动课件。

**导入交接包**沿用下列要求：

资源包为 **ZIP 文件，不超过 50 MiB**，包含以下三类资料：

| 资料 | 格式与作用 |
| --- | --- |
| 知识点资料 | Markdown，交接元数据中的 `resourceType` 为 `KNOWLEDGE`，说明需要教授的知识及来源 |
| 完整教案 | Markdown，交接元数据中的 `resourceType` 为 `LESSON_PLAN`，说明对象、目标、时间、任务和评价要求 |
| 项目启动课件 | PPTX，用于项目启动阶段的授课资源 |

两份 Markdown 使用 UTF-8，并在文件开头的 frontmatter 中标明 `handoffFormatVersion: 1` 和各自的资源类型。上传后如有多个候选文件，按页面提示选择各类资料。处理进度会自动更新，刷新页面不会中断资源包解析。

在“核对解析”中审阅课程概况、课时计划、五阶段安排、知识与证据、交付与评价。检查课程名称、学生基础、学习目标、阶段任务、最终成果和评分量规；五阶段时长之和应等于课程总时长。需要修正的字段可以直接编辑，确认后再开始课程生成。

如果资料中的课堂组织方式与系统流程冲突，页面会列出来源和建议。可以下载修改反馈交给资料提供方，也可以补齐要求后，按页面提示明确授权适配。

需要采用教材时，在“课程教材”中选择已就绪教材，可限定章节并指定主教材。课程固定使用所选教材的解析版本，并保留原文依据。补充知识资料支持 PDF、DOCX、PPTX、TXT 和 Markdown；这些资料用于生成，不会直接作为学生资料发布。

### 3. 生成、审阅与继续生成

确认资料后，可补充重点概念、学生常见困难和案例偏好。根据教学需要选择：

- **完整课程**：生成正式课程的全部知识小节，用于后续发布。
- **测试一节**：采用同一套输入和课程设计，选择一个完整知识小节试生成；测试结果不能直接发布，需要继续生成完整课程。
- **深度交互**：优先安排有实际操作价值的模拟、编程和探索页面。
- **深度作答**：每个知识小节使用一道综合简答题；默认检测根据教学需要使用单选、多选、判断、填空或拖拽配对等题型。
- **图片、语音、视频**：按需启用对应内容生成，能否使用取决于已配置的服务和页面需要。

生成页显示当前任务、知识图谱、大纲和课堂页面进度，并可预览已生成页面。出现教师审阅入口时，核对知识范围、教学顺序和页面内容，再按页面提示继续。

任务失败时，先查看页面记录的错误和已保存内容。系统会保留首稿与已完成页面，可使用“继续已保存首稿”或重生成失败阶段。需要调整要求时，从课程库打开原课程继续处理，避免因一次失败反复新建同一课程。

### 4. 发布与管理版本

完成生成后进入“发布中心”，核对课程总览、页面编排、学生课堂体验以及“检查与终审”。检查知识内容、讲稿、图片和互动是否适合学生；启用语音时，同时查看音频时长核查结果。估算时长与实测音频时长在页面中分别标注。

发布中心会分别显示必须完成的发布条件和课程核对提示。按页面要求补齐无法播放或缺失的资源，完成需要的教师确认后发布。课程核对提示供教师判断和授课参考，不应把提示显示当作课程质量已经通过。

课程播放区的思维导图按概念层级组织知识。讲解到特征、机制或流程步骤时，导图会定位对应细节点，并保留其所属分支。展开完整导图会暂停授课，可拖动、缩放、展开分支和查看节点详情；关闭后恢复原来的播放状态。较早课程尚未生成概念导图时继续显示原知识图。

白板完成一幅板书后会在本次听课中保留。使用白板顶部的上一页、下一页或页码选择框翻阅当前 PPT 页的板书；回到本页 PPT 后也可点击“翻阅板书”，无板书页面不显示该入口。翻阅时讲解继续推进，点击“返回当前讲解”可回到当前板面或 PPT，旧板书不会覆盖正在讲授的内容。切换 PPT 页时结束翻阅，返回原页面后仍可查看其已留存板书。

发布后的课程可以安排到教学班章节中。“下载 PPT”下载主课堂的逐页图片版 PPTX，保留页面中的中文、公式、箭头、边框与图像比例，不附带素材或原始资料。页内文字和图形不可单独编辑，讲稿保留在备注中，视频保留静态画面。“下载课程资源”仍可打包下载全部资源，其中的 PPT 也采用图片版。“课程版本记录”可查看已发布版本和历史草稿，并预览可用的历史课堂。恢复历史版本会建立新草稿，检查后再发布。

课程库可按名称或内容搜索，并区分生成中、未完成、已完成未发布、已发布和已归档。归档课程不能再添加到新章节，但已安排的课堂继续保留原内容；已归档课程可以恢复，也可以删除。删除后无法从课程库恢复，已安排的课堂和学习记录仍保留。

## 教师组织教学班

### 1. 创建并完善课程主页

在“教学班”点击“新建教学班”，填写课程名称和学期。新建后为草稿，不会立即向学生开放。进入教学班详情，在课程设置中完善课程介绍、整体大纲、开课与结课日期、封面，以及链接或 PDF 参考资料。

激活“学生邀请码”，可展示或复制邀请码，提供给学生注册或加入课程。在“学生管理”中按活动进度、学习状态和关注原因筛选学生，查看提交记录、课堂与评价，并协助重置密码。

### 2. 编排章节和活动

先添加章节，再在章节中添加学习内容：

| 类型 | 教师配置 | 学生使用 |
| --- | --- | --- |
| 课堂 | 选择课程库中未归档的已发布版本，可另配实验前后测 | 进入正在授课的场次；启用实验时先完成前测，结束后查看记录 |
| 作业 | 填写作业要求 | 输入作业正文并提交，开放期间可更新提交 |
| 测验 | 填写题目，每行一题 | 阅读题目并填写回答，提交后查看已保存内容 |
| 问卷 | 配置题目、选项、必答规则与展示图表 | 在独立问卷页作答和提交 |
| 后测 | 编辑题目与题组，或应用 CoTeach 后测模板 | 按题组分页作答，自动保存草稿，提交后回看已锁定答案 |
| 资料 | 填写学习说明，关联链接或上传 PDF | 阅读或打开资料，保存学习进度 |

教学班状态、章节开放和活动开放分别控制访问。完成编排后，将教学班设为开放，并打开学生需要学习的章节和活动。仅关联课堂教案不会自动开始上课。

活动创建后不能直接改成另一种类型。删除活动会从教师目录和学生端移除该项内容，已有课堂、提交与学习记录继续保留。

点击问卷、后测或测验的标题，默认打开作答结果。问卷展示选项分布与学生反馈；后测和测验展示学生作答进度，展开已提交学生可查看提交时的题目与正式答案。点击“编辑内容”才会打开编辑界面。

问卷、目录中的独立后测和课堂实验前后测具有不同的开放及提交规则，配置前先参照[问卷与测评选择](#问卷与测评选择)。

### 3. 开始课堂

从章节中的课堂活动进入教学工作台，核对课程资源和班级人数，选择本次项目实践的成果形式：**文档、Python、C 语言或其他成果**。每位进入课堂的学生获得一个私有项目空间。需要实验前后测时，先在活动的“实验配置”中保存题目。

点击“开始上课”后，学生从课程目录进入该课堂活动，再选择“进入课堂”。课堂使用教学班邀请码，无需再分发单独的课堂邀请码。

教师通过课堂工作台推进阶段、查看学生进度与作品、使用授课资源和投屏。学生按教师当前阶段进入对应任务；投屏可以要求学生同步观看，也可以提供可选观看入口。

## 五阶段课堂

新建场次的课堂流程如下。已有在授和已结束场次保留原流程；具体任务与时长取决于课程教案。

| 阶段 | 教师操作 | 学生操作 |
| --- | --- | --- |
| 1. 项目启动 | 使用启动课件说明情境、驱动问题、目标和交付要求 | 阅读项目说明，理解本次任务 |
| 2. 知识讲授 | 查看小节学习与检测情况，开展讲解、答疑和干预 | 分节学习课件与互动，完成节末检测，结合 AI 助教反馈巩固知识 |
| 3. 项目实践 | 查看学生文档、代码或上传作品及 AI 协作过程 | 在私有项目空间创作，与 AI 组员讨论、检查和修改成果 |
| 4. 成果汇报 | 查看推荐、浏览作品并选择汇报学生，发起全班投屏，结束后手动开始下一位 | 提交汇报材料，查看安排，自动跟随教师全屏展示 |
| 5. 项目评价 | 设置互评、查看个人档案、完成教师定评并发布结果 | 完成自评和分配的互评，查看已发布评价与 AI 过程报告 |

### 知识学习与随课问答

知识讲授的播放控制上方提供“这里没听懂？问一下”输入框。开始输入时，讲解和自动翻页暂停；发送后，问答在字幕所在区域展开。AI 根据问题优先采用本课程教材的相关内容，并结合当前讲解解释；教材未覆盖的问题也可运用模型知识解答。回答下方的教材小图标按书合并引用，悬停或点击可查看来源，再按需展开原文；补充解释不冒充教材内容。回答默认从开头阅读，流式生成不自动追到底部，手动滚动时保持阅读位置。可以追问当前页，也可以提出其他学习问题。

问答按学生和页面保存，回到该页可通过“本页问答”继续查看或追问。收起问答仍保持暂停，点击“继续学习”恢复播放。小测作答时不开放随课输入，提交后使用题目已有的助教讲解入口。

普通小测的助教讲解默认播放提前准备的统一讲解。选择题逐项说明判断依据，填空和配对题说明答案及对应关系；可以暂停、切题或“再听一遍”。学生答案在板书下方供对照，仍不明白时再发送追问，助教会结合自己的答案进一步解释。历史追问可回看，重新打开时不会自动朗读。预生成语音暂不可用时仍可阅读讲解，设备支持时使用浏览器朗读。

### AI 公开讨论

部署已启用公开讨论时，教师可在知识讲授阶段的“课堂工具”中打开“AI 公开讨论”，选择知识点、公开追问或观点辩论模式，编辑问题并点名学生。被点名的学生在自己的设备接受邀请，可以语音回答、改用文字或暂不参与；AI 回应由教师端统一播放。

教师可以暂停、恢复、切换发言学生或补充引导，最后选择“结束并总结”。如果页面未开放此能力，请由系统维护人员核对配置；它不影响学生个人随课问答。

### 项目评价与结束课堂

开课前在教学工作台调整量规。课程已有量规优先沿用；缺失时使用知识应用、问题解决与成果质量、证据论证、表达与反思四维等权模板。第五阶段的“课堂操作”提供评价设置、完成情况与个人档案，公开授课展示只显示评价任务说明。

学生依次完成“我的自评”和“分配给我的互评”。互评默认关闭，可选择全员分配、只评价汇报者或教师指定；默认每人两份，候选不足时自动减少。互评固定正式作品版本，默认匿名；不能观察的维度选“无法判断”。草稿自动保存，正式提交锁定，教师退回后可修订并保留历史。

教师可在第四阶段保存观察和评分草稿，第五阶段逐维定评。系统计算量规加权结果，调整最终成绩需要说明理由；自评、互评和 AI 建议分别呈现，不自动计入总成绩。未汇报不自动扣分。教师可按学生或批量发布评价及 AI 报告，互评缺交或报告生成失败不阻止定评和结课。

AI 过程报告贯穿课程，学习与实践阶段仅教师可见。报告引用小测、问答、保存版本变化和协作记录，分别说明判断、建议分或无法判断、证据缺口和改进方向；没有使用 AI 不扣分，只有最终文件时不能推断迭代过程。学生只看到教师已发布的固定版本，更新后需重新发布。文档和代码正式提交时可选填简短修改说明。

实验拓展位于主流程之外，前测课前进行，后测须等课堂结束后，由教师在活动的实验配置中按场次独立开放或关闭，默认关闭。进入第五阶段不会自动开放后测。目录中的独立后测仍单独控制。

教师切换阶段时，学生页面会同步到新的课堂阶段。结束课堂前确认资源和项目成果已保存；结束后学生进入只读回看，教师可查看课堂学习记录。需要再次使用同一课程授课时，在工作台创建新场次，保留原场次的记录。

## 学生完成项目成果

### 文档工作台

项目实践选择文档模式时，学生直接编辑项目文档，可围绕选中的文字或段落向 AI 组员提问、要求检查或提出修改。AI 批注与对话保留在工作台，便于继续讨论。

明确要求 AI 修改时，它会先判断能否完成；可承担的纠错、保留原意的润色和格式整理会先在正文中预览：红色表示拟删除，绿色表示拟新增。学生在聊天框点击确认应用后才会写入并保存，也可拒绝或要求修订；应用后可使用“撤销 AI 修改”恢复原文。仅讨论、检查不会改稿；核心分析、判断、结论或缺少材料的任务会解释原因并提供指导。尚有待确认修改时，应先处理这些内容再提交最终版。

文档会自动保存，也可主动点击“保存”。右上角统一显示当前稿件的“未保存”“保存中”“已保存”或“保存失败”状态，确认已保存后提交最终版。正式提交生成 Word 文件并保留版本，学生可以下载；继续修改后可再次提交新版本。

教师可在课程设置中开启“外部内容使用提醒”，发布后由新课堂继承，也可在开课设置或第三阶段单独调整。功能默认关闭，只监测第三阶段文档编辑区的较长文本粘贴。系统 AI 的直接插入及经核验的复制内容、空白模板和正常引用不产生这类提醒；检测在后台进行，不影响编辑、保存或提交。

收到“疑似核心内容直接粘贴，来源待核实”提醒时，学生可以继续编辑，或补充自写草稿、模板、引用、AI 辅助等来源说明。提醒不证明 AI 来源或违规。教师在“外部内容提醒”中查看片段、任务依据和学生说明，可标记已核实或排除误报；记录不自动计入评分，不在课堂投屏中展示。关闭功能停止新检测，已有记录继续保留。

### 代码工作台

代码模式支持 **Python 和 C 语言**，以项目文件组织代码，可新建、切换和删除文件。运行时可填写标准输入，查看输出、编译错误、运行错误或超时结果。

Python 默认运行 `main.py`，缺失时运行当前文件，支持项目内导入；C 语言编译项目中的全部 `.c` 文件。运行能力以系统提供的环境为准。

可以选择代码片段，请 AI 组员讨论、检查或提出修改。修改以文件差异预览呈现，学生确认后应用，也可拒绝或撤销。代码草稿会保存到当前项目；同步失败时，按提示下载本机草稿并处理保存错误。

### 其他成果与汇报材料

选择“其他成果”时，在本机制作作品，同时使用 AI 组员查资料、探讨问题和整理思路；完成后上传文件。成果汇报页也提供材料上传入口，支持 PDF、Word、PPTX、表格、图片、音视频、压缩包、代码和文本等文件，**单文件不超过 100 MiB**，可重复上传保留版本。

PDF 支持连续阅读和幻灯片式展示；文档可在页面中查看。其他材料按实际格式提供预览或下载，准备汇报时应先确认教师能打开所需内容。教师决定现场汇报名单和顺序，并发起投屏，学生等待点名后开展汇报。

第四阶段默认显示全部学生与作品预览，推荐名单在后台准备，可切换“推荐学生”查看。推荐人数优先使用教师保存的设置，其次采用教案要求；未指定时建议 3 人。推荐以实际提交内容的质量为主，补充首次提交时间、项目实践中的 AI 协作请求次数等理由。可展开理由查看原文依据；作品未完成分析或无法读取时会标明状态，教师仍可自行选择。推荐分数只服务于展示选人，不计入正式成绩。

学生主动提问或选区操作时才发起文档 AI 协作。保存、提交与现场选人不必等待推荐分析；推荐超时或失败时，教师仍可手动选人、调整顺序、投屏和进入下一阶段。标注“参考上次分析”或“部分正文初筛”时，教师应结合最新完整作品判断。

教师可一键采用推荐名单，也可在“全部学生”边浏览边加入、移除或调整未开始的汇报顺序。“设为下一位”只改变名单安排；点击学生姓名只切换本机预览。新推荐不会自动替换已经选定的学生。

点击“开始汇报并投屏”后，作品占满教师展示区，全班学生自动打开同一版本并跟随翻页、阅读位置。教师可通过“浏览学生作品”继续选人，学生保持观看当前作品。“退出本机全屏”只改变教师界面；“结束汇报”结束全班展示并提示下一位，由教师再次点击开始。课后可在普通工作台“更多 → 成果评分”中评价作品。投屏状态中的“作品已打开”统计实际加载回执，加载失败的学生可重试打开。

## 问卷与测评选择

| 类型 | 适用场景与入口 | 开放条件 | 提交后 |
| --- | --- | --- | --- |
| 问卷 | 章节中的“问卷”，收集选择和文字反馈 | 教学班、章节和活动开放 | 开放期间可更新回答，教师查看统计和 CSV |
| 独立后测 | 章节中的“后测”，单独安排知识与学习体验测评 | 教学班、章节和活动开放；无需前测或课堂参与 | 正式答案锁定，教师在活动结果页查看 |
| 实验前后测 | 课堂活动的“实验配置”，同一场次前后对照 | 前测在入场前完成；后测需完成前测与本场课堂学习、课堂已结束，并由教师开放该场次后测 | 各次正式答案锁定，保留同场前后测及实验导出 |

**自动保存草稿不等于正式提交。** 学生需检查必答项并点击正式提交，确认页面出现提交记录。问卷和独立后测不需要创建课堂场次。

### 独立后测

在章节中选择“添加学习内容”→“后测”，手动编辑题目或点击“应用 CoTeach 后测模板”。模板包含 9 道知识题、34 道课程学习体验题（CoI）、10 道系统使用体验题（C-SUS）和 1 道选填意见题。知识题答案键由教师补充；模板可继续编辑题干、选项、参考答案、题组和指代说明。

保存并开放后，学生直接从课程目录进入，按题组分页作答，答案和页码自动保存。正式提交后不能修改或再次作答；已有学生提交后，教师也不能更改题目和选项，但可调整标题、说明及开放状态。教师点击后测标题查看结果，也可在“学生管理”→“提交记录”中查看答案。

课程结束或学习记录结束后，未提交的独立后测关闭，停止保存草稿和提交；已提交答案在章节和活动仍可访问时只读显示。若希望学生结课后继续回看，请保留相应目录的访问入口。

### 问卷

教师在章节中添加“问卷”，设置说明与题目。每份问卷支持 **1–30 题**，题型为单选、多选和简答；选择题支持 **2–10 个选项**，可为选项提供补充输入。多选题可设置选择上限，题目可排序、删除并设置必答或选答。

学生从课程目录打开问卷，在独立答题页完成必答项后提交。课程和活动仍开放时，可以按页面入口更新回答；课程结束后查看已提交内容。

教师进入问卷统计页查看提交率、选项人数与比例、简答原文和关键词词云。单选支持环形图、条形图或柱状图，多选使用条形图或柱状图。点击词条可筛选相关回答；关键词在后台更新，尚未归入主题的原回答仍可查看。

统计页自动刷新，也可手动刷新、全屏展示或按题轮播。活动菜单可导出问卷 CSV。已有学生提交后，题目和选项锁定；仍可修改标题、说明或开放状态，需要改变题目时创建新问卷。

### 实验前后测

实验前后测属于课堂活动，从该活动的“实验配置”进入，使用“编辑题目”“批量添加与复用”“学生视角预览”完成配置，并点击“保存实验配置”。

- 支持单选、多选、判断、简答和量表题，可配置参考答案、题组说明、必答或选答规则。
- 可设置前后测共用题、前测专属题和后测专属题，也可使用 A/B 情境简答题配对。
- 可设置题目与选项随机顺序、前后测说明和建议作答时长。
- 可从已有课堂复制题组或整套配置，从表格粘贴题目，或通过页面导出的 JSON 配置文件备份与复用。
- 可一键应用“CoTeach 教学理解与学习体验”模板：前测为 9 道知识题，后测为相同的 9 道知识题、34 道 CoI 和 10 道 C-SUS；保留文档顺序与 1–5 分量表。后测最后单独提供 1 道“意见与建议（选填）”简答题，收集对系统或学习体验的意见，留空可直接提交，无需填写跳题原因。模板没有预设知识题答案键，教师可补充参考答案以自动计分。应用后可编辑、预览或撤销，保存后生效。
- 题组的“指代说明”在学生答题的每个相关分页中以绿色提示突出显示；教师预览、复制和 JSON 导入导出均保留说明。

启用实验模式需要同时配置前测和后测。每次前测或后测合计最多 100 题；共用题会分别进入前后测，A/B 情境题按学生分配的方案进入对应测验。

学生从课堂活动页打开前测，完成正式提交后再进入课堂。上课期间主入口为“进入课堂”，后测显示“尚未开放”。只有本场课堂已结束、学生已有本场入场与学习完成记录、后测已开放时，活动页才切换为“开始后测”。新场次由教师在结课后开放实验拓展后测；旧场次沿用第五阶段的开放标记，但同样必须等待课堂结束。答案和页码自动保存，但**草稿保存不等于正式提交**。提交前按页面提示检查必答项，正式提交后可以回看答案，不能直接改写本次已提交测验。课堂结束且满足上述条件后，已开放的后测可作答；教师关闭后测、教学班关闭或学习记录结束时停止保存和提交。已提交的答案仍可只读查看。

教师在实验拓展中选择场次，查看已进入本场课堂的学生提交情况，并可展开查看同场前后测正式答案。课堂学习记录中保留题目、答案与提交时间，也提供实验记录导出。

## 查看记录与导出

### 结束课堂后回看

学生课程主页分为课程学习、课程介绍和课程资料。课程学习显示章节活动、开放状态与完成进度，并提供下一项任务或继续学习入口。已结束课堂从历史课堂入口查看个人参与记录、成果和已有评价。

在课堂回顾中进入“回看 AI 课程”可浏览已保存课件；“我的作答”可查看当时的题目、答案、解析和已保存讲题记录。回看不重新提交答案、不补记学习进度，也不改变原始学习记录。项目成果只读；“项目评价”可回看已发布结果。新场次实验后测按教师独立开关开放，已提交的实验答案继续保留。

“结束本场课堂”和“结束教学班课程”作用范围不同：前者结束这一次授课，后者停止该教学班活动的学习写入。再次授课应创建新场次，保留上一场记录。

### 教师查看与导出

教师从教学班的“学生管理”查看学生活动进度、提交记录、课堂成果与版本、反思和评价。可以筛选学生后“导出当前结果”，选择需要的记录类别，并按需附带摘要 CSV。课堂活动也有“课堂学习记录”入口，可查看参与学生并进入个人档案评价。

学生档案导出、问卷 CSV 和实验记录导出包含实际教学记录及所选内容，应按教学用途保存和共享。

## 常见情况

| 页面提示或情况 | 处理方式 |
| --- | --- |
| 邀请码无效，或无法加入课程 | 请教师核对当前教学班邀请码和课程开放状态 |
| 章节或活动尚未开放 | 等待教师打开对应章节和活动；加入教学班不代表所有内容立即开放 |
| 课程库没有可选择的教案 | 先完成完整课程生成并发布，确认课程未归档 |
| 课堂尚未开始 | 请教师进入教学工作台并开始上课 |
| 进入课堂前要求前测 | 从课堂活动页完成本场前测，并确认已经正式提交 |
| 课堂实验后测未开放或未开启 | 核对实验配置、前测提交、本场学习完成记录及课堂结束状态，再等待教师开放后测；旧场次的第五阶段标记也须满足结课条件 |
| 目录中的独立后测无法作答 | 核对教学班、章节、活动及本人学习记录是否仍开放；正式提交后不能重答 |
| 文档、代码或测验提示待同步、保存失败 | 保留当前页面，检查网络并重试保存；有本机草稿下载入口时先下载留存 |
| 多个页面编辑同一份测验出现冲突 | 按提示选择服务器作答或当前页面作答后同步 |
| 课程已结束 | 通过原课程和历史课堂入口回看已保存内容；成果只读；新场次后测按独立开放状态作答，教学班关闭后不能补交 |
| AI 公开讨论没有声音或无法收音 | 检查教师播放设备、学生麦克风权限及语音服务；学生可使用文字回答 |
