# CoTeach 品牌资源

CoTeach 的品牌标识由“共同参与的教师与学习者、打开的书页、AI 连接节点与成长星芒”构成。静态标识与对外材料使用下列原始透明 PNG，不从截图重新裁切，也不改变宽高比例。首页及登录注册页的动画按新分镜使用下述独立组件。

| 版本 | 文件 | 推荐场景 |
| --- | --- | --- |
| 彩色横版 | `public/brand/coteach/horizontal-color.png` | 首页主视觉、内容页、浅色背景 |
| 深蓝横版 | `public/brand/coteach/horizontal-solid.png` | 顶栏、小尺寸品牌位、复杂浅色背景 |
| 彩色图形标 | `public/brand/coteach/icon-color.png` | 浏览器图标、应用图标、课堂侧栏 |
| 彩色竖版 | `public/brand/coteach/vertical-color.png` | 方形或竖向品牌场景 |

代码统一通过 `src/components/brand/coteach-logo.tsx` 使用这些资源。`horizontalCompact` 为现有界面的兼容变体，复用彩色横版，不额外制造第五套标识。

- 软件自有代码及文档按根目录 Apache-2.0 许可证提供；该许可证不额外授予 CoTeach、作者单位或第三方供应商的商标权。作者李科骏与单位北京师范大学的署名用于说明来源，不表示学校或第三方为衍生产品背书。
- 品牌名称统一写作 `CoTeach`；全大写场景写作 `COTEACH`。
- 对外定位统一为“AI 协同教学平台”，品牌主张统一为“共同教 · 共同学 · 共同创造”。
- 教师、学生与 AI 共同参与课堂；AI 直接参与知识讲授、互动答疑、协作与反馈，不仅作为辅助工具出现。
- 首页及账号入口不使用“项目式学习”或“PBL 平台”定义整个系统，标题直接表达品牌、页面对象或操作。
- 保留图片透明通道、安全留白、配色、渐变与原始比例。
- 不拉伸、不换色、不添加描边或阴影；界面确需光晕时由组件外层样式提供。
- 技术兼容标识（例如 `OPENPBL_*`、`X-OpenPBL-*`、旧 Cookie/JWT、数据目录和 systemd 单元名）不属于对外品牌，迁移完成前继续保留。

## LOGO 动画

首页主视觉、品牌理念区以及教师/学生的登录、注册页统一使用 `src/components/brand/coteach-logo-animation.tsx`，样式由相邻 CSS Module 隔离。

- 按动画分镜以 SVG 路径绘制书页、人物和星芒；字标直接引用原始彩色横版 PNG 中的字标区域，保持既有字形与配色，原文件不变。
- 所有位置采用约 3 秒的单次入场：人物在书页展开中段便开始同步翻起，随后星星与 Co、Teach 两段文字紧密衔接。入场完成后保持完整标识，仅刷新或重新进入所在页面时重播；滚动离开再回来不会重播，也不显示重播按钮。
- 恢复原始 LOGO 轮廓，不增加封面、内页或书本插画。两侧下层书页作为一组同时展开，两侧人物作为一组同时翻起，再点亮中央星星；左右两侧各共用一个动画变换与时间轴，收回时也同步。
- 星星显现后以 2.8 秒周期持续柔和呼吸发光，配合细小光点与 AI 节点传光。环境动效独立循环，首页主标识常驻后仍继续；父级显隐保证收回后不残留光效。
- 原始字标通过两组精确裁剪拆成 Co 与 Teach，先后显现、错峰退场；完整展示后每 3.2 秒持续有克制的柔光掠过。保留原始字形、颜色与最终位置。
- CSS 仅动画化 transform 和 opacity；不使用 GIF、逐帧 React 更新或动画依赖。固定 SVG 画布比例避免布局跳动，绘制限制在品牌区域；首页主视觉和账号页背景保持静止，减少持续重绘。
- 进入可视区域才播放，离开视口或切换浏览器标签时暂停。减少动态效果或缺少 IntersectionObserver 时显示完整静态标识。组件的服务端 HTML 在不执行 JavaScript 时也是完整静态标识；整页的流式加载框架可能仍依赖 JavaScript，不能将组件回退等同于整站无脚本可用。
- 手机登录注册页在表单上方显示紧凑动画，桌面保留左侧品牌区域。静态顶栏、侧栏和浏览器图标继续使用原始 PNG。
