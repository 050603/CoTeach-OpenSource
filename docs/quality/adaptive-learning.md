# 自适应学习与个性化资源合同

新版教师自动生成默认制作知识讲授课程，不自动创建个性化方案。本文说明仓库仍维护的独立入口学习包、教师确认的资源预生成和学生播放路径；没有确认方案的课程直接进入完整主课。主课生成与恢复见 [课程生成合同](../course-generation.md)。

## 本课知识与课前先修

`CourseContent.knowledgePoints` 保存本课负责教会和评价的目标。知识图谱可额外保存 `instructionalRole: prerequisite` 的课前先修节点；本课节点为 `lesson`。`foundation` 表示本课内容层级，不能据此推断学生课前已经掌握。

真实先修须同时说明：按学段或课程递进为何理应在课前学过、缺失为何直接阻断本课目标，以及一道题能够观察的掌握边界。仅有帮助的背景知识、本课目标的同义改写、简化例题或预习任务不成为先修诊断。

图谱使用结构化关系类型、强度和依据。只有来自先修节点的 `required-prerequisite`、`required` 依赖才支持前测候选；本课目标之间使用支撑、应用、对比或迁移关系，不把教学先后混成课前先修。无结构化依据的旧图谱不直接改变学生路径。

独立入口包读取最终主课页面、目标、图谱、学段和学情，审视实际先修依赖及主课是否已在使用前完成解释。年级、画像或既往课程缺失表示未知；“入门”“启蒙”“无需编程”不能代替概念依赖分析，也不能证明学生已会。

## 入口学习包与教师确认

[course-entry-generation.ts](../../src/lib/course-entry-generation.ts) 联合生成入口分析、先修、前测、补学和可选拓展，再通过有界的独立审校形成最终方案与图谱，原子保存。该入口的审校属于入口包生成策略，不是新版主课生成中的全课循环审校。失败时保留此前方案，不能把未经审校的候选标记为已通过。

先修数量和入口时间由 [course-entry-policy.ts](../../src/lib/course-entry-policy.ts) 根据课时、学段、目标规模、课程模式及已审校先修推导，不统一强制每门课 2–4 项。低年级、全部目标确属基础起点且没有已审校先修时允许零先修；既有已审校节点不能被后续容量建议直接删掉。当前前测结构最多保留 5 题，实际选择同时受入口政策约束。

每个被诊断先修对应一道题和一份独立补学资源，资源只解决该缺口。它以误解定位、必要短讲解或例子及衔接检查帮助进入主课，不提前教主课核心目标。全部方案记录逐目标决策、先修依据、诊断边界、资源新增价值与可能重叠的主课页面。

教师确认方案与分支后才能编排资源，学生运行时还要求先修语义审校状态为 `passed`。草稿、被关闭方案或未审校旧方案不改变学生学习路径；自动生成首稿不冒充教师确认。

## 备课资源与就绪

已确认且尚无可复用资源的分支使用同一课堂生成、渲染和媒体链路预生成。分支知识范围、目标、学情与真实片段时长优先，不套整课最小时长，也不追加知识点填时间。共享案例、术语、条件与主课边界保持一致，生成提示不能声称知道某个学生的实际答案或经历。

每个分支完成后独立保存课堂 ID、页数、生成签名与状态；并发池最多同时处理 3 份资源，模型调用仍经过课程生成全局闸门。一份失败不覆盖其他成功分支或已保存主课堂。分支正文变化后教师需重生成相关资源。

资源必须先生成配置提供方和音色的语音，才能标记 `ready`。缺音频不能由学生播放器隐式切换到浏览器原生语音。学生编排消费已经 `ready` 的课堂资源；必需补学尚未就绪时显示明确问题和重试入口，不临时创造内容、不先播放主课再跳回补学。可选拓展未就绪时继续主课。

## 学习证据与连续播放

学习证据按知识点记录，不用前测总分给学生贴基础、普通或优秀标签。前测只判断课前先修缺口；本课成绩来自实际主课学习检测。默认新版主课按小节设置检测，多个检测分别保留作答和知识点证据，不沿用旧版“全课只有一处测验”的描述。

前测提交后，系统在主课首次播放前按方案顺序组装全部命中补学，形成“补学 A → 补学 B → 主课第一页”的队列。命中先修缺口的必需补学不占拓展名额，也不因拓展剩余时间条件被跳过。刷新后依据已保存前测和分支运行记录恢复队列。

学生完成对应主课检测后，只有关联知识点达到配置掌握阈值、到达正确插入位置、资源已确认且就绪、未播放、具有新增价值、路径名额和剩余时间足够，才插入拓展。多个关联知识点使用最低得分判断，不以总分掩盖局部缺口。未达标进入解析和教师统计，不追加反复测验或自动重讲循环。

补学和拓展在同一主课播放器内连续插入，完成后返回既定后继页面。主课仍是独立完整叙事，不依赖只有部分学生看过的补学或拓展；插入资源直接讲解并自然衔接，不重做整课问候、开场或告别。教师可查看每次资源选择的实际条件、证据与原因，学生看到学习内容。
