# 合成蓝图回归样例

这两个 JSON 保留首稿兼容、概念定义归属和孤立节点恢复所需的结构；证据正文、完整解释和例子已重新编写为测试专用的合成材料，不是教材摘录、模型原始响应或真实课堂记录。主题名称、教学方法名称和流程标签用于检验通用教学契约。

- `blueprint-definition-ownership-first-draft.json` 保留完整命题、概念定义、五个特征、六步流程、前置依赖及尚未归属页面的完整案例。合成积木与虚构花坛用于检验边界，不代表经过实验验证的教学效果。
- `teaching-methods-blueprint-first-draft.json` 保留两种独立概念、解释节点、三张有内容的页面和空的末尾小测。空占位可折叠，有实际内容的小测仍须拒绝丢弃。

相关测试仍要求原文完整投影、不修改候选稿、完整概念归属、已保存首稿续跑和真实失败状态保留。改写样例时不能通过删掉流程、定义、条件或案例来降低这些要求。

关联的[证据列表样例](../../textbook/__fixtures__/README.md)和[容量/排版样例](../../openmaic/generation/__fixtures__/README.md)使用同类合成内容。`course-source` 是模拟输入的来源类型，不表示引用了外部教材；JSON 内 `provenance` 标明实际用途。仓库整体许可证仍由维护者另行确定。
