# 合成证据列表

`teaching-methods-first-draft.json` 是为测试编写的虚构教学活动手册。正文与步骤摘录采用合成花坛案例，教材标题、时间、来源 UUID 和证据指纹均不对应真实教材库或课堂数据。

它保留两个独立的有序列表：支架式五步和抛锚式六步，两者都以“效果评价”结束；还保留单独的五项特征列表和概念定义，防止将不同证据混合。测试同时检查带引号动作名称的等价识别、漏步骤、顺序反转以及不能合并两个列表。修改内容须继续通过 `course-visual-binding.test.ts`，不能只保留标题或削减条目。

同类[蓝图样例](../../course-design/__fixtures__/README.md)验证确认与续跑契约。上述材料为回归输入，不是教材引用或真实模型调用记录。
